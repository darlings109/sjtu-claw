# Material Summary Skill

## 适用场景
- 汇总课堂笔记
- 整理学习材料
- 调研资料结构化输出

## 工作流程
1. 明确汇总范围（指定文件或目录）
2. 使用 read_file 读取材料内容
3. 归纳整理成结构化摘要
4. 通过 workspace update tool 保存

## 输出结构
- 整体概述
- 核心观点/知识点（按主题分组）
- 关键引用
- 个人思考与疑问
